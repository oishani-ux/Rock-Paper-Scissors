🪨📄✂️ Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript. First to 5 points wins!

🔗 Live Demo: rck-paper-scissors.vercel.app

Features
Classic Rock / Paper / Scissors gameplay against the computer
First to 5 points wins the game
Live scoreboard that updates each round
Round-by-round result feedback
Winner announcement banner once the game ends
Reset button to start a new game anytime
Tech Stack
HTML5 – page structure
CSS3 – styling and layout
JavaScript (Vanilla) – game logic and DOM interaction
How to Play
Click Rock, Paper, or Scissors.
The computer randomly picks its move.
The winner of the round is decided using classic rules:
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
The scoreboard updates after every round.
The first player (you or the computer) to reach 5 points wins the game.
Click Reset Game to play again.
Project Structure
├── index.html    # Page markup
├── style.css     # Styling
└── script.js     # Game logic
Running Locally

No build tools or dependencies needed — it's plain HTML/CSS/JS.

Clone the repository:
bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
Open index.html in your browser.

That's it — no server or installation required.
